# Extractos de B3

Subí acá los extractos de **Movimentação** de la Área do Investidor de B3, en Excel (`.xlsx`).

1. Área do Investidor → **Extratos** → **Movimentação**.
2. Elegí el período y descargá el Excel.
3. Subilo a esta carpeta (en GitHub: *Add file → Upload files*).

El GitHub Action "Importar proventos B3" procesa todos los archivos de esta carpeta y actualiza
`data/proventos-recebidos.json`. Podés subir extractos que se superpongan: los pagos repetidos se cuentan una sola vez.
